Bloque I · Números y Operaciones

De los naturales a los complejos: clasificación, divisibilidad, potencias, raíces, logaritmos y cálculo mental. Cursos: 1º ESO → 2º Bachillerato.

Los conjuntos numéricos 1º-2º ESO → Univ.

Todo lo que cuentas cabe en una jerarquía de conjuntos: ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ. Naturales ℕ = {0, 1, 2, …}; Enteros ℤ añaden los negativos; Racionales ℚ son todas las fracciones ab con b ≠ 0 (decimales exactos o periódicos); Irracionales ℝ∖ℚ no se pueden escribir como fracción (π, e, √2); y Complejos ℂ = a + bi resuelven lo que en ℝ no tiene solución, como x² + 1 = 0.

√2 ∈ ℝ pero ∉ ℚ  ·  i = √−1 ∈ ℂ
Ejemplo resuelto
Clasifica: −5, 0,75, π, √9, 3i. −5 ∈ ℤ (no en ℕ); 0,75 = 3/4 ∈ ℚ; π es irracional; √9 = 3 ∈ ℕ; 3i solo existe en ℂ.

Divisibilidad, MCD y mcm 1º-2º ESO

Un número es divisible por otro si el resto es 0. Criterios rápidos: por 2 si acaba en par; por 3 si la suma de cifras es múltiplo de 3; por 5 si acaba en 0 o 5; por 9 como el 3 pero con el 9; por 11 alternando signos de las cifras. Todo número compuesto se descompone en números primos de forma única (Teorema Fundamental de la Aritmética).

  • MCD (máximo común divisor): factores comunes al menor exponente → sirve para simplificar fracciones.
  • mcm (mínimo común múltiplo): factores comunes y no comunes al mayor exponente → para sumar fracciones.
  • Relación: MCD(a, b) · mcm(a, b) = a · b.
36 = 2²·3² ; 48 = 2⁴·3 → MCD = 12 ; mcm = 144

Fracción generatriz y decimales 3º-4º ESO

Todo decimal racional se convierte en fracción resolviendo una pequeña ecuación lineal. Exacto: 0,35 = 35/100 = 7/20. Periódico puro: el periodo va sobre 9 con tantas cifras como el periodo. Periódico mixto: tantos 9 como cifras del periodo seguidos de tantos 0 como cifras del anteperiodo.

N = 2,3535… ⇒ 100N − N = 233 ⇒ N = 23399
Mixto: 0,1666…
x = 0,1666… ⇒ 10x = 1,666… y 100x = 16,666… Restamos: 90x = 15 ⇒ x = 15/90 = 1/6. Regla rápida: (anteperiodo+periodo − anteperiodo) / (9…90…0) = (16 − 1)/90.

Potencias y notación científica 1º ESO → 2º Bach

aⁿ significa multiplicar a por sí mismo n veces. Propiedades clave (con a, b ≠ 0):

  • aᵐ · aⁿ = aᵐ⁺ⁿ  ·  aᵐ / aⁿ = aᵐ⁻ⁿ  ·  (aᵐ)ⁿ = aᵐ·ⁿ
  • a⁰ = 1  ·  a⁻ⁿ = 1/aⁿ  ·  a^(m/n) = ⁿ√(aᵐ)
  • (a·b)ⁿ = aⁿ·bⁿ  ·  (a/b)ⁿ = aⁿ/bⁿ
La velocidad de la luz: 3·10⁸ m/s · un átomo: ~10⁻¹⁰ m

Radicales: raíces y racionalización 3º ESO → 1º Bach

ⁿ√a es el número que elevado a n da a. El índice es n y el radicando a. Raíces de índice par solo existen en ℝ si a ≥ 0. Propiedades: ⁿ√(a·b) = ⁿ√a · ⁿ√b ; ⁿ√(a/b) = ⁿ√a / ⁿ√b ; (ⁿ√a)ᵐ = ⁿ√(aᵐ) = a^(m/n). Simplificar: saca fuera los factores con exponente ≥ al índice.

√72 = √(36·2) = 6√2  ·  3/(√2) = 3√2/2
Racionalizar con raíz en el denominador
Multiplica numerador y denominador por la misma raíz: 5/(√3) = 5√3/3. Si es suma, usa el conjugado: 1/(√2+1) · (√2−1)/(√2−1) = √2−1.

Logaritmos y exponenciales 4º ESO → 2º Bach

log_a(x) responde: ¿a qué exponente hay que elevar a para obtener x? Es la función inversa de aˣ. Se usan para medir escalas enormes: pH, decibelios, sismología, interés compuesto.

  • log(xy) = log x + log y  ·  log(x/y) = log x − log y
  • log xⁿ = n·log x  ·  log_a(a) = 1 ; log_a(1) = 0
  • Cambio de base: log_a(x) = ln x / ln a
ln(eˣ) = x  ·  e^(ln 5) = 5  ·  log₂ 8 = 3

Bloque II · Álgebra

Del lenguaje algebraico a matrices: ecuaciones, sistemas, desigualdades y polinomios. Prueba el Solver Prodigio más abajo.

Ecuaciones de 1º y 2º grado 1º ESO → 4º ESO

Una ecuación es una igualdad con incógnita. De 1er grado: se despeja pasando términos con la balanza invertida. De 2º grado (ax² + bx + c = 0), la fórmula universal:

x = −b ± √(b² − 4ac)2a
  • Discriminante Δ = b² − 4ac: si Δ > 0 dos soluciones reales; Δ = 0 una doble; Δ < 0 ninguna en ℝ (dos complejas).
  • Teorema de Vieta: x₁ + x₂ = −b/a ; x₁·x₂ = c/a.
Ejemplo: x² − 5x + 6 = 0
a=1, b=−5, c=6 → Δ = 25 − 24 = 1 → x = (5 ± 1)/2 → x = 3 o x = 2. Comprobación: 3+2 = 5 ✓ y 3·2 = 6 ✓.

Sistemas de ecuaciones lineales 3º ESO → 1º Bach

Buscamos el punto (o recta/plano) común a varias rectas. Tres métodos clásicos en 2×2:

  • Sustitución: despeja una incógnita en una ecuación y sustitúyela en la otra.
  • Igualación: despeja la misma incógnita en ambas e iguala.
  • Reducción: multiplica para que los coeficientes de una incógnita sean opuestos y suma.
x + y = 5 & x − y = 1 → (S = {x=2, y=3})
En 3×3 se usa Gauss (triangularizar la matriz ampliada) o la regla de Cramer con determinantes. Un sistema puede ser compatible determinado (1 solución), indeterminado (infinitas) o incompatible (ninguna).

Polinomios y productos notables 4º ESO → 1º Bach

Identidades que conviene memorizar porque aceleran todo el álgebra posterior:

  • (a + b)² = a² + 2ab + b²  ·  (a − b)² = a² − 2ab + b²
  • (a + b)(a − b) = a² − b²  ·  (a + b)³ = a³ + 3a²b + 3ab² + b³
  • Regla de Ruffini divide P(x) entre (x − a); el resto es P(a) (teorema del resto) → factoriza probando raíces enteras divisores del término independiente.
x² − 9 = (x + 3)(x − 3)  ·  x² + 2x + 1 = (x + 1)²

Inecuaciones e intervalos 3º ESO → 2º Bach

Se resuelven como ecuaciones, pero al multiplicar o dividir por un negativo se invierte el signo. La solución es un intervalo, no un punto.

−2x + 6 > 0 ⇒ x < 3 ⇒ (−∞, 3)
Notación de intervalos
[a, b] incluye extremos; (a, b) los excluye; semirrectas: [a, +∞). Valor absoluto: |x| < a ⇔ −a < x < a ; |x| > a ⇔ x < −a o x > a. Cuadráticas: estudia el signo de la parábola respecto a sus raíces.

Matrices y determinantes 2º Bach → Univ.

Una matriz es una tabla de números que representa transformaciones y sistemas. Se suman elemento a elemento; se multiplican fila por columna (solo si columnas(A) = filas(B)). El determinante det(A) mide el área/volumen escalado: A⁻¹ existe ⟺ det(A) ≠ 0.

det [ a b ; c d ] = ad − bc
Ejemplo 2×2
A = [2 1; 5 3] → det = 2·3 − 1·5 = 1 ≠ 0 → A⁻¹ = (1/1)·[3 −1; −5 2]. Con matrices se discuten sistemas por Rouché-Frobenius: compatible ⇔ rg(A) = rg(A*).

Progresiones y sucesiones 4º ESO → 1º Bach

Aritmética (se suma d cada paso): aₙ = a₁ + (n−1)·d ; Sₙ = n·(a₁ + aₙ)/2. Geométrica (se multiplica por r): aₙ = a₁·rⁿ⁻¹ ; Sₙ = a₁(rⁿ − 1)/(r − 1). Si |r| < 1, la suma infinita converge: S∞ = a₁/(1 − r).

2, 6, 18, 54… (r = 3)  ·  1 + ½ + ¼ + … = 2

Bloque III · Geometría

Plana, del espacio, analítica y trigonometría. Fórmulas de áreas/volúmenes, distancias y razones trigonométricas con ejemplos.

Áreas y perímetros (plana) 1º-3º ESO

Las indispensables:

  • Rectángulo: A = b·h · Cuadrado: A = l²
  • Triángulo: A = (b·h)/2 · Equilátero: A = (√3/4)·l²
  • Paralelogramo: A = b·h · Rombo: A = (D·d)/2 · Trapecio: A = ((B + b)·h)/2
  • Círculo: A = πr² · Longitud L = 2πr · Sector: A = (πr²·α)/360°
Pitágoras: a² + b² = c² → hipotenusa de catetos 3 y 4 = 5

Volumen y superficie del espacio 3º ESO → 1º Bach

Prisma y cilindro: V = A_base · h. Pirámide y cono: V = (A_base · h)/3. Esfera: V = (4/3)πr³ y S = 4πr². Principio de Cavalieri: cuerpos con la misma sección en cada altura tienen el mismo volumen.

Cono r=3, h=4 → V = π·9·4/3 = 12π ≈ 37,7 u³
Teoremas de Pappus-Guldinus
Al girar una figura alrededor de un eje exterior, el área/volumen generado = longitud/área de la figura × distancia recorrida por su centroide. Así se deduce el toro: V = 2πR·πr².

Geometría analítica 4º ESO → 2º Bach

Traducimos figuras a ecuaciones con coordenadas. Recta: punto-pendiente y = y₀ + m(x − x₀), con m = tan α. Distancia de punto a recta:

d(P, r) = |Ax₀ + By₀ + C| / √(A² + B²)
  • Paralelas: m₁ = m₂ · Perpendiculares: m₁·m₂ = −1
  • Circunferencia: (x − a)² + (y − b)² = r²
  • Vector v = (v₁, v₂), módulo |v| = √(v₁² + v₂²); producto escalar u·v = |u||v|cos θ.

Trigonometría 4º ESO → 2º Bach

En el triángulo rectángulo: sen = co/hip, cos = ca/hip, tg = sen/cos. Valores notables: sen 30° = 1/2, cos 60° = 1/2, tg 45° = 1. Una vuelta = 360° = 2π rad → π rad = 180°.

sen²x + cos²x = 1  ·  tg x = sen x / cos x
  • Suma: sen(a±b) = sen a·cos b ± cos a·sen b
  • Doble ángulo: sen 2x = 2 sen x cos x ; cos 2x = cos²x − sen²x
  • Resolución de triángulos: Teorema del seno a/sen A = b/sen B = c/sen C ; del coseno a² = b² + c² − 2bc·cos A.

Vectores y rectas en el espacio 2º Bach

En ℝ³ usamos base i, j, k. Suma componente a componente; producto escalar u·v = u₁v₁+u₂v₂+u₃v₃ (0 ⇔ perpendiculares); producto vectorial u×v da un vector perpendicular a ambos con módulo = área del paralelogramo. Recta = punto + t·vector director; plano = punto + dos direcciones (normal n = u×v).

Mixto (u, v, w) = u·(v×w) = det[u; v; w] → volumen

Semejanza, Thales y proporción áurea 3º-4º ESO

Dos figuras son semejantes si conservan los ángulos y los lados están en proporción k. Entonces Área se multiplica por k² y el volumen por k³. Thales: rectas paralelas cortan a dos secantes en segmentos proporcionales. La razón áurea φ aparece en pentágonos y naturaleza:

φ = (1 + √5)/2 ≈ 1,61803…

Bloque IV · Funciones y Cálculo

Dominio, gráficas, límites, derivadas e integrales: del análisis básico de 4º ESO al cálculo de 2º Bachillerato y universidad.

Concepto de función y dominio 4º ESO → 1º Bach

Una función f asigna a cada x del dominio un único y. Para hallar el dominio en ℝ: denominadores ≠ 0, raíces de índice par con radicando ≥ 0, logaritmos con argumento > 0. Paridad: f(−x) = f(x) par (simétrica al eje Y); f(−x) = −f(x) impar (simétrica al origen).

f(x) = √(x−3)/ln(x+1) → Dom = [3, +∞) ∖ {0}

Funciones elementales 4º ESO → 1º Bach

Familias que debes reconocer de memoria: lineal y = mx + n (recta, pendiente m); cuadrática y = ax² + bx + c (parábola, vértice en x = −b/2a); polinómica; racional (hipérbolas con asíntotas); exponencial y = aˣ (crecimiento explosivo); logarítmica y = ln x (su inversa); a trozos.

Vértice de y = x² − 4x + 3 → x = 2, y = −1 → V(2, −1)

Límites y continuidad 1º-2º Bach

lim f(x) describe hacia dónde tiende la función. Indeterminaciones típicas: 0/0, ∞/∞, ∞−∞, 0·∞ → se resuelven factorizando, racionalizando o con L'Hôpital (derivar arriba y abajo). f es continua en a si lim(x→a) f(x) = f(a). Asíntotas: vertical donde f → ±∞; horizontal si lim(x→±∞) f = k; oblicua y = mx + n con m = lim f/x.

lim(x→2) (x² − 4)/(x − 2) = lim (x + 2) = 4

Derivadas: reglas y aplicación 2º Bach → Univ.

f′(a) es la pendiente de la recta tangente en a: el ritmo de cambio. Tabla básica: (xⁿ)′ = nxⁿ⁻¹, (sen x)′ = cos x, (cos x)′ = −sen x, (eˣ)′ = eˣ, (ln x)′ = 1/x, (aˣ)′ = aˣ·ln a.

  • Producto: (fg)′ = f′g + fg′ · Cociente: (f/g)′ = (f′g − fg′)/g²
  • Cadena: (f∘g)′(x) = f′(g(x))·g′(x)
  • Estudio: f′ > 0 crece; máximos/mínimos donde f′ = 0 cambiando de signo; cóncavidad con f″.
Recta tangente: y = f(a) + f′(a)(x − a)

Integrales y áreas 2º Bach → Univ.

La integral es la operación inversa a derivar: acumula. Primitiva: ∫xⁿ dx = xⁿ⁺¹/(n+1) + C ; ∫1/x dx = ln|x| + C ; ∫eˣ dx = eˣ + C. El Teorema Fundamental del Cálculo conecta derivada e integral:

∫ₐᵇ f(x) dx = F(b) − F(a) (Barrow) → área entre curvas
Métodos
Sustitución (cambiar u = g(x)), integración por partes ∫u dv = uv − ∫v du, y fracciones parciales para racionales. Volumen de sólido de revolución: V = π∫ₐᵇ f(x)² dx.

Sucesiones y series 1º Bach → Univ.

Una sucesión aₙ converge a L si sus términos se acercan a L indefinidamente. Series notables: geométrica Σ arⁿ converge si |r| < 1 (suma = a/(1−r)); armónica Σ 1/n diverge aunque sus términos → 0; Σ 1/n² = π²/6 (Basilea). Criterios: comparación, cociente (D'Alembert), raíz.

Σ 1/2ⁿ = 1  ·  Fibonacci: Fₙ = Fₙ₋₁ + Fₙ₋₂ → Fₙ₊₁/Fₙ → φ

Bloque V · Estadística y Probabilidad

Datos, medidas, azar, distribuciones y inferencia. Del 1º ESO al 2º Bachillerato (y selectividad).

Medidas de centralización y dispersión 2º ESO → 2º Bach

Media x̄ = Σxᵢ/n · Mediana: valor central al ordenar · Moda**: el más repetido. Dispersión: rango = max − min; varianza s² = Σ(xᵢ − x̄)²/n; desviación típica s = √s². Coeficiente de variación CV = s/x̄ compara dispersiones relativas.

Notas 5,7,7,8,8,8,9 → x̄ = 7,43 ; Me = 8 ; Mo = 8

Probabilidad: Laplace, condicional y Bayes 4º ESO → 2º Bach

Regla de Laplace: P(A) = casos favorables / casos posibles (equiprobables). Condicional: P(A|B) = P(A∩B)/P(B). Independientes: P(A∩B) = P(A)·P(B). Probabilidad total y Bayes (invertir condiciones):

P(Aᵢ|B) = P(B|Aᵢ)·P(Aᵢ) / Σⱼ P(B|Aⱼ)·P(Aⱼ)
Ejemplo test médico
Enfermedad 1% (P(E)=0,01); test + dado enfermo: 99%; test + dado sano: 5%. P(E|+) = 0,99·0,01 / (0,99·0,01 + 0,05·0,99) ≈ 16,5%. Intuitivamente "positivo" no implica casi seguro: Bayes sorprende siempre.

Combinatoria 1º Bach → Univ.

Contar sin listar: Permutaciones Pₙ = n! (orden importa, sin repetir). Variaciones Vₙ,ₖ = n!/(n−k)!. Combinaciones (sin orden): C(n,k) = n!/(k!(n−k)!). Con repetición: VRₙ,ₖ = nᵏ y CR(n,k) = C(n+k−1, k).

Manos de póker: C(52,5) = 2.598.960

Distribuciones: binomial, Poisson y normal 2º Bach

Binomial B(n, p): k éxitos en n ensayos independientes → P(k) = C(n,k)pᵏ(1−p)ⁿ⁻ᵏ, μ = np, σ² = np(1−p). Poisson P(λ): sucesos raros en un intervalo, μ = σ² = λ. Normal N(μ, σ): campana de Gauss; se estandariza con Z = (X − μ)/σ y se lee en la tabla típica. Regla 68-95-99,7.

P(X ≤ x) = Φ((x − μ)/σ)

Inferencia: muestreo e intervalos de confianza 2º Bach

Estimamos la media poblacional μ con la media muestral x̄. Intervalo de confianza (nivel 1−α, σ conocido):

IC = x̄ ± z_(α/2) · σ/√n
Para el 95%, z = 1,96. Contrastar hipótesis: H₀ frente a H₁, estadístico crítico, región de rechazo y errores tipo I (rechazar siendo cierta) y II (aceptar siendo falsa). El p-valor: probabilidad de observar algo tan extremo si H₀ fuese cierta.

Tablas de frecuencia y gráficos 1º-4º ESO

Frecuencia absoluta fᵢ (repeticiones), relativa fᵢ/N, acumuladas Fᵢ y Fi. Con datos agrupados en intervalos: marca de clase xᵢ = extremo medio; la media pondera por fᵢ. Gráficos: barras (categórica), histograma (continua, áreas proporcionales), sectorial (porcentajes), box-plot (cuartiles Q₁, Q₂, Q₃ y bigotes).

Percentil Pₖ: valor que deja a su izquierda el k% de datos
